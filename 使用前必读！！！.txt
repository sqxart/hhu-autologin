【这是什么】
  一个放在自己电脑上的小工具，替你盯着校园网：
  掉线了它自动帮你重新登录，不用再打开浏览器点登录。
  常州（金坛）、江宁、西康路三个校区都适用。

【怎么用：三步】
  1. 先把压缩包找一个固定的位置，你记得的位置，不会移动/乱动的位置，比如c盘/D盘（D:\校园网工具），在那里新建一个文件夹，把压缩包放进去。然后再解压。不要放桌面！不要放桌面！不要放桌面！也不要留在下载文件夹里。

  2. 先在浏览器里手动登录一次校园网（让工具能抓到你的账号）
     然后双击文件夹里的 hhu_gui.exe
     如果 Windows 弹出蓝色警告窗口：点「更多信息」→「仍要运行」
        （小软件没买签名证书，Windows 对谁都这么提示，不是病毒）

  3. 在打开的窗口里依次操作：
     点「一键抓取账号和服务」 → 输入你的校园网密码 →
     勾选「开机自启」 → 点「保存配置」
     
  4.我想把它放到桌面上怎么办？
     先单击选中hhu_gui.exe，然后右键，再右键菜单里找到“创建快捷方式”选项，找不到？那就点开“显示更多选项”再找一遍。然后把你创建快捷方式拖到桌面。不要移动hhu_gui.exe！不要移动hhu_gui.exe！不要移动hhu_gui.exe！


【想确认它真的在工作】
  · 窗口顶部会显示「状态: ● 在线 / 离线」和「后台守护: 运行中」
  · 点「立即检测登录状态」，会直接告诉你结果
  · 点「打开日志文件夹」，看 hhu_login_debug.log 最后一行时间
    （每分钟一条心跳；出现 "login http ... result:success" 就是帮你重连了一次）

【常见问题】
  · 双击没反应 / 窗口闪一下就不见了
    → 先看上面蓝色警告那条；仍然不行，把 logs 文件夹里的 hhu_login_debug.log
      发给作者（或截图），能直接看出原因
  · 开着 Clash 等代理软件会有影响吗
    → 不会。本工具的请求全部直连、不经过代理，Clash 开着也正常工作
  · 提示「断路保护已触发」
    → 说明密码不对，工具已停止重试（不做无用功）。
      把密码改对后点「保存配置」，它会自动恢复
  · 提示「认证被拒 / 密码错误」
    → 改过密码？在窗口里重新输入密码并保存即可
  · 笔记本睡眠唤醒后暂时没网
    → 最多等一分钟，后台任务会自动把它拉回来
  · 想彻底卸载
    → 右键托盘图标退出控制台，在窗口里取消勾选「开机自启」，
      然后删掉整个文件夹（不会残留别的文件）

【文件夹里都有什么】
  hhu_gui.exe             ← 双击打开（可视化控制台，日常只用它）
  hhu_login.exe           ← 后台自动检测&登录的小程序（不用手动开，控制台会调用它）
  hhu_campus_report.exe   ← 帮采集校园网配置的小工具（运行后会自动抓取校园网配置并且生成txt，不用管这个）
  使用前必读！！！.txt     ← 就是本文件

【不想用了如何卸载】
设置取消勾选开机自启，保存配置。
把解压出来的整个文件夹删掉。

【隐私与安全】
  · 学号和密码只存在本文件夹的 config.ini 里（明文保存，方便离线登录）
  · 不会上传到任何服务器；但请别把 config.ini 发给别人或传到网上
  · 开源地址：https://github.com/sqxart/hhu-autologin （觉得好用欢迎点个 ⭐）
