河海大学（Hohai University）校园网自动登录守护。掉线自动重登、无浏览器、纯 Python 标准库零依赖。

> 适用对象：使用学校 ePortal 网页认证的河海同学（江宁 / 常州 / 西康路三校区无线网均适用）。
> 针对问题：*每 1~2 天被踢下线*、*每次都要打开浏览器点登录*

## 🚀 三步上手（不需要任何电脑知识）


> **系统要求**：打包版 exe 需要 **Windows 10（1607+）或 Windows 11，64 位**——不想装 Python 就用打包版。
> 源码方式支持 Windows / macOS / Linux，需 Python 3.8+（macOS/Linux 走命令行方式，见下方）。

1. 打开 [Releases 下载页](../../releases)，下载 **`hhu-autologin_v1.4.2_portable.zip`**（便携版压缩包），解压后按里面的 **「使用前必读！！！.txt」** 操作
   ⚠️ 不要点 "Source code"——那只是源代码，不是软件
   （也可以只下载 `hhu_gui.exe` + `hhu_login.exe` 两个文件，放进同一个文件夹，比如 `D:\校园网工具`）
2. 将你下载的**`hhu-autologin_v1.4.2_portable.zip`**放在一个固定位置，不要放在桌面也不要留在下载文件夹，放在一个你记得在哪且之后不会再移动/乱动的地方，或者直接去C盘（D盘也行）新建一个文件夹放进去，再解压**`hhu-autologin_v1.4.2_portable.zip`**。
3. 在浏览器登录一次校园网，保持在已登录的校园网环境下进行后续操作 → 双击 `hhu_gui.exe` → 点「一键抓取账号和服务」→ 输入密码 → 勾选「开机自启」→ 点「保存配置」
4. 完成！以后开机自动守护，掉线自动恢复（不想用图形界面就看下方命令行方式）

> - 首次运行如果 Windows 弹蓝色警告：点 **「更多信息」→「仍要运行」**（没签名的小软件都这样）
> - 文件夹请放在 **D 盘C盘等固定位置**，这个位置应该是固定位置你记得在哪且不会再移动它了，放好之后再解压，不要放桌面或下载文件夹（计划任务会记住这个位置，移动后需重新设置开机自启）
> - 想确认它在工作：双击 `hhu_login.exe --check`，或看 `logs\hhu_login_debug.log` 最后一行的时间

## 特性

- **掉线自动重登**：每分钟检测一次，在线时 0.2 秒静默退出，掉线后 3 秒内自动恢复
- **配置向导**：`--setup` 自动抓取账号与服务，只需输入密码；换服务商密码可沿用
- **零依赖**：纯 Python 标准库，不装 selenium、不装 chromedriver、不开浏览器
- **服务自动适配**：自动解析登录页的服务下拉框（校园网 / 移动 / 电信 / 联通），按关键词匹配，三校区通用
- **系统通知**：登录成功/失败弹 Windows 原生通知（Win10/Win11），带冷却防刷屏；控制台「设置」区可分别开关「掉线自动恢复时通知我」「自动登录失败时通知我」，两个都关即完全静默
- **断路保护**：密码错误被服务器拒绝后立即停止重试（不撞接口、不触发验证码锁定），改完密码点「保存配置」或「重置断路保护」即恢复
- **验证码状态识别**：触发验证码时明确告诉你原因和恢复方法，而不是无限失败
- **SSID 门卫**：只在校园 WiFi 下工作，连手机热点时不瞎折腾
- **开机自启**：install.bat 一键注册 Windows 计划任务

## 快速开始

### 方式一：下载打包好的 exe（推荐，无需装 Python）

1. 到 [Releases](../../releases) 下载 `hhu_login.exe`，放到任意固定目录（建议如 `D:\hhu-autologin\`）
2. 同目录创建 `config.ini`（可直接复制 `config.example.ini`），填写学号和密码
3. 双击 `hhu_login.exe --check` 看自检结果
4. 双击 `install.bat`，完成。以后开机自动守护，不用管

> **SmartScreen / 杀毒软件提示**：未签名的 exe 首次运行会被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」即可；个别杀软对 PyInstaller 打包的程序有误报，可添加信任或改用方式二（源码运行）。

### 方式二：Python 运行（自备 Python 3.8+）

```bat
git clone https://github.com/sqxart/hhu-autologin.git
cd hhu-autologin
copy config.example.ini config.ini
notepad config.ini          # 填学号、密码
python hhu_login.py --check # 自检
install.bat                 # 注册每分钟计划任务（无窗口运行需 pythonw 或 exe）
```

### 方式三：macOS / Linux（进阶）

核心逻辑跨平台，无需 install.bat，用 cron 替代计划任务：

```bash
python3 hhu_login.py --check          # 先自检
crontab -e                            # 加入一行（每分钟检测）：
* * * * * /usr/bin/python3 /path/to/hhu_login.py --quiet
```

- **不想常驻？两个自动退出开关**：①「上线后自动退出」——登录成功就退，适合只想开机自动登录一次的人；②「运行 N 分钟后自动退出」

## 命令一览

| 命令 | 作用 |
|---|---|
| `hhu_login.py` | 跑一次：在线秒退，掉线自动登录（计划任务就是调它） |
| `hhu_login.py --setup` | 配置向导：自动抓取账号与服务，只需输入密码（换服务商也用它，密码可沿用） |
| `hhu_login.py --loop [分钟]` | 常驻循环模式（默认间隔读配置） |
| `hhu_login.py --check` | 自检：配置 / SSID / 在线状态 / 门户链路 / 服务列表 |
| `hhu_login.py --logout` | 注销当前会话（切换账号时用） |
| `hhu_login.py --clear-flag` | 密码改对后清除断路器标志（`--setup` 会自动清） |
| `uninstall.bat` | 卸载计划任务 |

## 配置向导（--setup）：不用手写配置文件

已登录校园网时运行 `hhu_login.py --setup`（exe 双击不行，需在终端运行），账号和当前服务**自动抓取**，你只需要**输入两遍密码**：

```
== hhu-autologin 配置向导 ==
[*] 校园网内且已在线，正在抓取当前会话的账号与服务 ...
[√] 抓取到账号: 2535010118
[√] 抓取到服务: 校园外网服务(out-campus NET)
    -> 按关键词「校园网」保存（不带校区字样，换校区通用）
回车确认，或输入 n 手动填写:
请输入校园网密码（输入不回显）:
```

几种实际场景的行为：

- **首次配置**：先在浏览器手动登录一次，再运行向导 → 账号/服务全自动，只输密码
- **换服务商**（联通到期、新开移动）：用新服务在浏览器登录一次 → 运行向导 → 抓到新服务；账号没变则**密码自动沿用，无需重输**，回车两下就完成
- **换密码**：运行向导，密码环节输 `n` 重新输入（或直接改 config.ini 后跑 `--clear-flag`）
- **不在校园网运行**（如手机热点）：向导会明确提示，转为手动填写学号和服务关键词；配置写好后回校园网自动生效
- 向导写完配置会自动清除断路器，改完立刻生效

## 它是怎么工作的（原理）

把学校网络想象成一个大院子，门口有个"门卫"（上网控制器）：

```
 你 ──访问任意网址──> 门卫：「没登记，不许过」
 你 ──被转送到登录页──> ePortal（网址后面带一串加密的"通行证参数"）
 你 ──账号密码+通行证──> 认证接口 InterFace.do?method=login
 认证接口 ──拿通行证找门卫放行──> 上网 ✅
```

本脚本做的就是第三步的自动化，有几个**实测踩坑后才知道**的关键点：

1. **通行证参数不能省**：直接打开 `eportal.hhu.edu.cn` 主页是拿不到有效通行证的（会弹"设备未注册"）。必须先访问 `1.2.3.4` 这类会被门卫劫持的地址，跟着 302 跳转拿到带参数的登录页
2. **服务名必须动态解析**：下拉框显示名和实际提交值不一致（例：电信显示"中国电信(CTCC NET)"，实际提交"中国电信(常州)"）。服务列表是登录页 JS 调 `getServices` 接口动态注入的，登录页原始 HTML 里根本没有；脚本掉线时会直接调同一接口拉取列表再按关键词匹配
3. **所有参数要双重 URL 编码**：页面 JS 对 userId/password/service/queryString 都做了两次 `encodeURIComponent`，少一层都会失败
4. **密码不加密**：`passwordEncrypt=false`，页面里的 RSA 加密代码是注释掉的，不要画蛇添足

## 常见问题对照表

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面弹"设备未注册,请联系管理员" | 直接打开门户主页，缺通行证参数 | 从 `1.2.3.4` 或任意 HTTP 网址进入；本脚本自动处理 |
| `result:fail 用户名或密码错误` | 密码错 / 密码改了没同步 | 改 `config.ini` 后运行 `--clear-flag` |
| 提示"触发验证码" | 只在**浏览器网页**里连续输错时触发（实测：脚本直连接口**连错 10 次也不触发**，响应无任何变化，验证码按网页会话计数而非账号；正确密码第 11 次直接成功） | 脚本流程不会遇到；若浏览器里遇到了，输一次验证码正常登录即可 |
| `www.msftconnecttest.com` 解析失败 | 该域名在河海网络永久被过滤，正常现象 | 检测脚本不要用它（本项目已避开） |
| 开着 Clash 时怎么都登不上 | 旧版本（v1.4.0 及之前）的请求会跟随系统代理，内网门户请求被代理送挂 | **v1.4.1 起已根治**：本工具所有请求强制直连、不读系统代理，Clash 随便开；旧版本请升级，或暂时关闭系统代理 |
| 会一直弹通知吗 | 不会 | 成功通知只在真的执行登录后弹一次；失败通知有冷却时间（默认 30 分钟一条）；密码错误触发断路器后只弹一条"需要人工介入" |
| 睡眠唤醒后没网 | 计划任务唤醒后下一分钟才触发 | 等一分钟；或手动跑一次 |

## 断路器说明

为保护你的账号（密码连错 3 次会触发验证码）和学校认证服务器，认证被拒一次后脚本会**立即停止重试**并在 `logs/auth_failed.flag` 留下原因。这不是坏了——修正 `config.ini` 后运行：

```bat
hhu_login.py --clear-flag
```

最多一分钟后自动恢复。

## 服务选择（三校区 + 运营商）

`config.ini` 的 `service` 填**关键词**即可（不带校区字样），脚本运行时会拉取**当前校区的服务列表**再按关键词匹配——在常州校区命中"中国联通(常州)"，在江宁校区就命中对应江宁的选项，换校区不用改配置：

```ini
service = 校园网    ; 或 移动 / 电信 / 联通
```

> 运营商服务（中国移动 / 中国电信 / 中国联通）已实测支持（2026-09，常州校区，移动与联通均验证登录成功并确认实际提交值）。电信流程相同但尚无卡实测。注意：脚本保证"选对服务项"，你的运营商账号在对应校区是否有宽带权限取决于套餐本身。

## 已知限制

- 仅实测 Windows 11 + 常州校区无线网（校园网 / 移动 / 联通服务均验证）；江宁、西康路校区的服务列表由服务器按校区下发，江宁实测关键词全部唯一命中（2026-09 同学采集验证），机制上自动适配；macOS / Linux 下核心逻辑通用（`--loop` 模式），安装脚本未适配
- 想让其他校区的同学帮忙验证？把 `hhu_campus_report.exe` 单独发给他（**免装 Python**），他在自己校区 WiFi 下双击、选校区，会生成一份脱敏报告（不含密码，学号打码）
- 接网线（无 WiFi 环境）请把 `config.ini` 里的 `wifi_ssid` 留空
- 你的密码明文保存在本地 `config.ini` 里（本项目 `.gitignore` 已排除它，请勿手动提交）
